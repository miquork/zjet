\begin{frame}{The slope and the mean answer different questions}
\small With $x=f_u^{gen}$ and $y=m_u^{reco}$, on the same matched population:
\[
R_0=\frac{\langle xy\rangle}{\langle x^2\rangle},\qquad
R_{\rm mean}=\frac{\langle y\rangle}{\langle x\rangle},\qquad
b=\frac{\operatorname{Cov}(x,y)}{\operatorname{Var}(x)},\quad a=\langle y\rangle-b\langle x\rangle.
\]
\begin{center}\input{output/taggerRu/summary_table.tex}\end{center}
\centering $50<p_{T,Z}<70$ GeV; existing full MC, truth 0 kept separate.
\medskip

\raggedright $R_0$ minimizes $\langle(y-Rx)^2\rangle$. It does not guarantee
$\langle y/R\rangle=\langle x\rangle$. These are central values without
joint-moment uncertainties; no significance claim is made.
\end{frame}

\begin{frame}{A data closure proxy is not an independent measurement of $R_u$}
\begin{columns}[c,onlytextwidth]
\column{.53\textwidth}\includegraphics[width=\linewidth]{closure_proxy.pdf}
\column{.45\textwidth}\small
For $R_2=R_n=1$,
\[
x_c=1-m_2-m_n=1-m_0+m_u.
\]
Regressing $m_u$ on $x_c$ reuses the same recoil fluctuations. The shared noise
and leading-jet resolution can bias the slope.
\medskip

Compare this proxy with truth in MC first. A data/MC proxy difference is a
control discrepancy, not automatically $R_{u,data}/R_{u,MC}$.
Do not tune $R_u$ to force $C_A/C_F$ or $\alpha_s$ agreement.
\end{columns}
\end{frame}

\begin{frame}{Purity and HDM: test the inversion rather than hiding it}
\small
Data tag fractions do not determine every truth-to-reco transition.
Compare an unmodified MC purity model with the existing minimum-KL/IPF
construction at fixed MC truth fractions; report rank/condition without a unity prior.
\medskip

For a reco category with truth purities $P_f$, define
\[
N_f=m_{0f}-m_{nf}-m_{uf},\qquad D_f=1-m_{nf}/R_n-m_{uf}/R_u.
\]
HDM is $\sum_f P_fN_f/\sum_fP_fD_f$, not $\sum_fP_fN_f/D_f$.
The crossed fit uses the former, with flavor scales multiplying $N_f$ while
holding the MC $D_f$ fixed. This is an explicit model, not a model-free unfolding.
\medskip

MC-as-data closure and the historical/corrected row-permutation test are required.
Conditional fit errors omit MC/template and model uncertainties.
\end{frame}
\begin{frame}{Next production: diagnose the origin of the recoil slope}
\small
\begin{itemize}
\item Native generator HT threshold vs the reco-selected, uniquely matched
GenJet partition. Compare both on the same complete-match subset.
\item Preserve $f_n+f_u$ under partition migration; unmatched jets remain an
explicit acceptance limitation, not an assumed zero-energy contribution.
\item Store joint $u$/$n$ moments: zero-intercept, affine, and partial regression
can distinguish unclustered response from $n\leftrightarrow u$ mixing.
\item Separate truth/reco flavor and low/high $\rho$ (25 GeV boundary).
\item Twenty deterministic event-hash blocks retain correlated probes and
allow merge-safe delete-group uncertainty estimates for the slope.
\end{itemize}
\medskip
Recommended order: tagger/MC closure $\to$ partition/affine closure $\to$
data proxy validation $\to$ calibrated HDM $\to$ an independent FSR interpretation.
