\begin{frame}{Scope and conventions}
  \begin{itemize}
    \item The primary reference is the HDM-corrected Z+jet data/MC response in
          average-$p_T$ binning. Differences are displayed in per mille.
    \item HDM uses the active \texttt{softrad3.C} responses $R_n=1.00$ and
          $R_u=0.92$ and the exact Z+jet master equation.
    \item The direct new-minus-legacy curve is decomposed exactly into the six
          data and MC inputs with order-independent Shapley contributions.
    \item The global-fit comparison additionally multiplies HDM by each file's
          stored previous JEC, exactly as \texttt{globalFit.C} does. Its
          raw-HDM and previous-JEC terms are displayed separately.
    \item W$\rightarrow qq'$ is retained as an independent response reference;
          photon+jet is not treated as independent because it currently uses
          effectively the same leading-object method as legacy Z+jet.
    \item Logarithmic axes use explicit 30, 100, 300, 1000, and 3000 labels
          whenever those values lie inside the plotted range.
  \end{itemize}
\end{frame}
