\begin{frame}{How to read the comparison}
  \begin{itemize}
    \item Each page keeps the same three-column layout: data, MC, and the
          derived result. The result is data/MC for DB and MPF, but data--MC
          for MPF components, PF fractions, and rho.
    \item Upper pads overlay the baseline, synchronized legacy, and new method
          on fixed axes. Lower pads compare both candidates with the baseline.
    \item Lower pads use only points with exactly matching bin centers.
    \item Statistics distributions are normalized to unit area. Their third
          column is a normalized data/MC shape ratio; raw yields are tabulated
          separately because the historical MC has a different normalization.
    \item MPFnu is reconstructed from MPFn and MPFu with the soft-recoil
          responses documented in the generated deck. Generator and
          reconstructed balance closures are MC-only diagnostics; direct
          balance in data and data/MC is labelled separately.
    \item Dedicated global-fit pages show HDM after multiplication by each
          input file's own previous-JEC curve and the Run2024I axis factors.
    \item Machine-readable diagnostics are in \texttt{summary.tsv} and
          \texttt{normalization.tsv} under \texttt{output/compareJECdata}.
  \end{itemize}
\end{frame}
