\begin{frame}{Pure-parallel HDM gives a full-rank four-flavor fit}
\begin{columns}[T,onlytextwidth]
\column{0.51\textwidth}
\begin{align*}
P_{\mathrm{data}}(f\mid t) &=
\frac{W_{\mathrm{data}}(t,f)}{\sum_{f'}W_{\mathrm{data}}(t,f')},\\
R_{\mathrm{data}}(t) &= \sum_f P_{\mathrm{data}}(f\mid t)
R_{\mathrm{MC}}(t,f)\,k_f,\\
R_{\mathrm{HDM}} &= \frac{m_0-m_n-m_u}
{1-m_n/R_n-m_u/R_u}.
\end{align*}
\column{0.47\textwidth}
\begin{block}{Current choices}
\begin{itemize}
\item $|\eta_{jet}|<1.3$ and pure parallel window
\item $p_{T,Z}>30$ GeV
\item $R_n=1.00$, $R_u=0.92$
\item merged component means, never event-wise HDM
\item four reco rows, four truth columns
\item rank $4/4$, condition number 4.98
\end{itemize}
\end{block}
\end{columns}
\end{frame}

\begin{frame}{A finite-energy cascade need not equal $C_A/C_F$}
\begin{columns}[c,onlytextwidth]
\column{0.56\textwidth}\includegraphics[width=0.92\linewidth]{color_cascade_benchmark.pdf}
\column{0.42\textwidth}
\scriptsize
The soft one-emission limit gives $C_A/C_F=2.25$. As a qualitative
multiplicity-cascade benchmark,
\[
r(Q)=\frac{C_A}{C_F}\left[1-r_1\gamma_0-r_2\gamma_0^2+\cdots\right],
\qquad \gamma_0=\sqrt{2C_A\alpha_s/\pi},
\]
gives 2.04, 1.78, and 1.79 through $O(\gamma_0)$, $O(\gamma_0^2)$, and
$O(\gamma_0^3)$ at $m_Z$ for $n_f=5$. This is not a fixed two- or
three-emission prediction for our
$f_n+f_u$: the latter is energy weighted, non-global, clustered, and selected.
This standard expansion approaches 2.25 from below as $Q$ grows, so a falling
measured ratio needs observable/selection, UE, or flavor-mixture effects rather
than ``deeper trees'' alone.
\par\vspace{0.3em}\tiny 3NLO coefficients: Capella et al.,
arXiv:hep-ph/9910226; experimental context: DELPHI,
arXiv:hep-ex/9903073.
\end{columns}
\end{frame}

\begin{frame}{One resolved emission gives only a scale benchmark for $f_n+f_u$}
\begin{columns}[c,onlytextwidth]
\column{0.56\textwidth}\includegraphics[width=0.92\linewidth]{lo_out_of_cone_benchmark.pdf}
\column{0.42\textwidth}
\scriptsize
For a toy angular interval $R<\theta<1$,
\[
\langle f_{out}\rangle_i\simeq
\frac{\alpha_s(Q)}{2\pi}\ln\!\frac{1}{R^2}
\sum_{i\to jk}\int_0^1 dz\,\min(z,1-z)P_{i\to jk}(z).
\]
At $R=0.4$ the finite-$z$ integrals are 1.35 for a quark and 3.18 for a
gluon (including $n_f=5$ $g\to q\bar q$), a ratio 2.36. Around $m_Z$ this
gives roughly 4.6\% and 10.9\%. A quantitative comparison requires at least
NLO small-$R$ jet functions plus non-global/recoil, hadronization, UE and the
actual Z+jet cuts; the curve is deliberately labelled a toy LO benchmark.
\par\vspace{0.3em}\tiny For a controlled NLO small-$R$ framework see
Kang--Ringer--Vitev, arXiv:1606.06732; recoil and non-global effects in jet
shape: Cal--Ringer--Waalewijn, arXiv:1901.06389.
\end{columns}
\end{frame}

\begin{frame}{Data can constrain $R_u$ only after a closure assumption}
\small
The measured components obey
\[
 m_2=R_2f_2,\qquad m_n=R_nf_n,\qquad m_u=R_uf_u,
 \qquad f_2+f_n+f_u=1.
\]
They do not identify $R_2$ and $R_u$ simultaneously. With externally fixed
$R_2$ and $R_n$ one can form
\[
 f_u^{closure}=1-\frac{m_2}{R_2}-\frac{m_n}{R_n},\qquad
 R_u^{closure}=\frac{\langle m_u f_u^{closure}\rangle}
                         {\langle(f_u^{closure})^2\rangle}.
\]
The next output stores all three event-level moments in data and MC. MC also
stores the true-$f_u$ regression, so the leading-jet resolution, JER migration,
and flavor-dependent closure bias can be measured rather than guessed. This
is a conditional in-situ constraint, not yet an absolute data-only $R_u$.
\end{frame}

\begin{frame}{The next output makes the UE-hole subtraction explicit}
\small
For the same lepton-cleaned jets with $p_T>15$ GeV that enter reconstructed $H_T$, store
\begin{align*}
A_{\parallel} &=-\sum_j A_j\cos\Delta\phi(j,Z),\\
u_{\rm hole} &= \frac{\rho A_{\parallel}}{p_{T,Z}},\\
m_{nu}^{\rm FSR-like} &= m_n+m_u-u_{\rm hole}.
\end{align*}
\begin{itemize}
\item The scalar $\sum A_j$, $A_\parallel$, $u_{\rm hole}$, and corrected sum are stored separately for every reference-$p_T$/flavor cell.
\item Transverse pairs use the same combined $Z+$sideband projection as their $m_u$ estimator.
\item Matched MC also stores $m_{n,u}^{reco}$, $m_{n,u}^{gen}$, their products, and generator squares, enabling flavor-resolved mean-ratio and regression-slope $R_n,R_u$ estimates.
\item This preserves freedom to replace $\rho$ or model a $p_T$-dependent effective response after production.
\end{itemize}
\end{frame}

\begin{frame}{The low-$p_T$ b feature has several testable mechanisms}
\begin{columns}[T,onlytextwidth]
\column{0.48\textwidth}
\begin{block}{Physical effect}
Neutrinos from semileptonic b-hadron decays lower visible response, but a
sharp change below 100 GeV is unlikely to be the dead cone alone. Changing
$g\to b\bar b$ admixture, decay-product migration across $R=0.4$, the Type-I
threshold, muon overlap removal, tag-response sculpting, and JER migration can
all make the selected effect strongly $p_T$ dependent.
\end{block}
\column{0.50\textwidth}
\begin{block}{Next-run control}
\begin{itemize}
\item response components versus single-b, double-b and other GenJet heavy-hadron topologies;
\item response versus jet PF-muon fraction as a semileptonic proxy;
\item $m_u^{gen}$ versus topology to test whether the feature is already particle-level;
\item continuous response-versus-score profiles for DeepJet, ParticleNet and UParT QvG, avoiding a single working-point comparison;
\item next: GenPart-ancestry neutrino fraction and $R_{gen+\nu}/R_{gen}$ to separate decay loss from detector response.
\end{itemize}
\end{block}
\end{columns}
\end{frame}

\begin{frame}{Recommended path before the full 2024 campaign}
\begin{enumerate}
\item Run a crossed 2-by-2 closure: old/new tags times legacy/all-pairs response on the same selected events. This is the shortest path to localizing the gluon sign change.
\item Replace fixed flavor fractions only after a data-constrained model exists; until then show the current IPF result as conditional on MC truth marginals.
\item Validate the new projected-area UE subtraction and flavor-resolved $R_n,R_u$ slopes before changing nominal HDM constants.
\item Fit $m_n+m_u-u_{\rm hole}$ jointly across the four reference-$p_T$ choices and propagate their migration covariance.
\item Add PSWeight, JER, tagger, heavy-neutrino, direct-versus-splitting, and flavor-fraction variations; later combine Z+jet, gamma+jet, and dijet data for a Jet-Topics flavor-fraction constraint.
\end{enumerate}
